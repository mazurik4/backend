# Бэкенд сайта «Автодіагностика — Київ»

API на FastAPI для сайта [autoworkshop.com.ua](https://autoworkshop.com.ua).
Сам сайт (HTML/CSS/JS) лежит в отдельном репозитории
[auto-diagnostics](https://github.com/mazurik4/auto-diagnostics) и публикуется через GitHub Pages.

## Как всё устроено

```
Посетитель ──► autoworkshop.com.ua (GitHub Pages, репозиторий auto-diagnostics)
                      │  fetch (CORS разрешён только для этого домена)
                      ▼
               backend-cmr4.onrender.com (Render, этот репозиторий)
                      │
                      ▼
               Postgres на Neon (заявки, новости, статистика)
```

- **Render** (бесплатный тариф) засыпает без запросов; от этого есть пинг
  `.github/workflows/keep-warm.yml` (каждые 10 минут обращается к `/api/news`,
  заодно будит базу Neon).
- **Деплой:** любой коммит в `main` автоматически пересобирает сервис на Render
  (1–4 минуты).

## Что умеет API

| Метод и адрес | Доступ | Назначение |
|---|---|---|
| `POST /api/callback` | публичный | заявка «Замовити дзвінок» (имя, телефон, симптом) |
| `GET /api/requests` | ключ | список заявок |
| `PATCH /api/requests/{id}?status=done` | ключ | отметить заявку обработанной |
| `GET /api/news` | публичный | последние 5 новостей для карусели |
| `GET /api/news/{id}/image` | публичный | фото новости |
| `POST /api/news/sync` | ключ | синхронизировать посты из Google сейчас |
| `POST /api/news/unhide` | ключ | вернуть скрытые вручную посты |
| `DELETE /api/news/{id}` | ключ | скрыть новость на сайте |
| `GET /api/admin/check` | ключ | проверка ключа на входе в админку |
| `POST /api/event` | публичный | анонимная статистика (просмотры, клики) |
| `GET /api/stats?days=30` | ключ | сводная статистика для админки |

«Ключ» — это заголовок `X-Admin-Key` со значением переменной `ADMIN_KEY`.
Автодокументация со всеми запросами: `/docs`.

## Переменные окружения (Render → Environment)

Значения хранятся **только** в Render и никогда не попадают в код или репозиторий.

| Переменная | Для чего |
|---|---|
| `DATABASE_URL` | строка подключения к Postgres (Neon) |
| `ADMIN_KEY` | пароль для админки и просмотра заявок |
| `GBP_CLIENT_ID`, `GBP_CLIENT_SECRET`, `GBP_REFRESH_TOKEN` | доступ к Google Business Profile API |
| `GBP_ACCOUNT_ID`, `GBP_LOCATION_ID` | номера аккаунта и точки в Google (только цифры) |

Без `GBP_*` бэкенд работает, но новости не обновляются.

## Новости из Google

- Бэкенд читает посты профиля («Автоелектрик Київ | Діагностика автомобілів») через Google Business Profile API
  (только чтение, права `business.manage`).
- Берутся активные посты **с фото и текстом**; на сайте остаются 5 самых новых, старые вытесняются сами.
- Синхронизация запускается сама не чаще раза в 30 минут при визитах на сайт,
  а также кнопкой в админке (`/admin.html`).
- Фото сжимаются (ширина до 1200 px, JPEG) и хранятся в базе.
- Скрытый кнопкой «Сховати» пост не возвращается, пока не нажата «Показати приховані пости знову».
- Если синхронизация показывает ошибку, текст ошибки виден в админке под кнопкой.
  Типичные причины: отозван доступ приложения Google (нужно заново получить refresh token),
  не включён API в Google Cloud, не заданы переменные `GBP_*`.

## Анонимная статистика

Сайт отправляет на `/api/event` события: просмотр страницы, нажатия «Подзвонити», Telegram, маршрут,
отправка формы, выбор симптома, раскрытие услуг и FAQ, клики по новостям и меню.
Хранятся только название события, короткая подпись, домен источника перехода, тип устройства
(телефон/компьютер) и время. **IP-адреса, cookie, имена и телефоны в статистику не попадают.**
Записи хранятся 365 дней. Просмотр — в админке (`/admin.html`).
Чтобы не считать свои визиты, один раз откройте сайт с `#notrack` в адресе.

## Локальный запуск

```
pip install -r requirements.txt
$env:DATABASE_URL = "строка-подключения-к-Postgres"   # PowerShell
$env:ADMIN_KEY = "любой-свой-пароль"
uvicorn main:app --reload
```

Проверка: http://127.0.0.1:8000/docs. База данных нужна Postgres (SQLite больше не используется).

## Безопасность

- Не храните ключи и строки подключения в файлах репозитория.
- Файлы баз данных (`*.db`) и `.env` в репозиторий не загружаем.
- CORS ограничен доменами `autoworkshop.com.ua` и `www.autoworkshop.com.ua`.
